# Tela-de-busca-inteligente-BBTS

🔍 Busca Inteligente de Startups

Projeto desenvolvido a partir de uma proposta da Residência do Porto Digital, focado na criação de duas telas de busca inteligente para um site de busca e cadastramento de startups.

📌 Sobre o projeto

Este projeto contempla o desenvolvimento de duas telas principais voltadas à busca inteligente de startups, utilizando apenas HTML, CSS e JavaScript, sem uso de frameworks.

A proposta simula um sistema real onde usuários podem pesquisar e visualizar startups cadastradas, priorizando usabilidade, organização das informações e uma navegação intuitiva.

🖥️ Telas desenvolvidas

- Tela de **Busca Inteligente de Startups**
- Tela de **Resultados / Visualização das Startups Cadastradas**

✨ Funcionalidades

- Campo de busca inteligente  
- Exibição dinâmica dos resultados  
- Organização das startups por informações relevantes  
- Interface interativa  
- Layout responsivo  

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript
